## 📖 使用方式

### Codex 中使用
将 skill 目录放入 `.codex/skills/` 或通过 `codex skills install` 安装。

### OpenClaw 中使用
将 skill 放入 `~/.openclaw/workspace/skills/` 目录，OpenClaw 会自动识别。

### Claude Code 中使用
将 skill 放入 `~/.claude/skills/` 目录。
